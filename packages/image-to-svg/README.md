# @chalidade/image-to-svg

Trace PNG and JPG images into SVG vectors (color or black and white) with VTracer compiled to WebAssembly. Nothing is uploaded.

This is the [Image to SVG](https://toowl.my.id/#/image-to-svg) tool from
[chalidade/tools](https://github.com/chalidade/tools), packaged as a custom
element so you can drop it into your own site. Try it there first.

## Use

```html
<script type="module" src="./dist/element.js"></script>

<image-to-svg></image-to-svg>
```

### Attributes

| Attribute | Value | Default |
| --- | --- | --- |
| `theme` | `auto` (follows the system), `light`, `dark` | `auto` |
| `lang` | `en` or `id`, the UI language | the visitor's browser language |

The element uses Shadow DOM, so your site's CSS can't break it (and vice versa).
