README setiap paket berbahasa Inggris, karena halaman npm dibaca orang dari

## Cara kerjanya

**Satu sumber kode.** Paket tidak menyalin kode tool. Ia mem-build kode yang
sama dengan yang dipakai situs (`src/tools/<tool>/`) lewat alias `@` ke
`../../src`. Memperbaiki tool di situs berarti memperbaikinya di paket juga,
cukup build ulang dan terbitkan versi baru.

Setiap paket berisi dua hal:

- **`dist/element.js`**: custom element (mis. `<screen-recorder>`) yang
  merender komponen React tool ke dalam **Shadow DOM**, jadi CSS situs pemasang
  tidak merusaknya dan sebaliknya. React dan CSS ikut dibundel, sehingga cukup
  satu `<script type="module">`. Lewat jsDelivr, semua paket npm otomatis
  tersedia sebagai CDN gratis.
- **`dist/index.js`**: API tanpa UI (fungsi biasa, tanpa React) untuk developer
  yang ingin membuat tampilan sendiri.

Hal yang perlu diperhatikan saat membuat paket baru:

- **Warna tema**: token di `src/theme.css` didefinisikan untuk `:root, :host`,
  jadi berlaku juga di Shadow DOM.
- **`@property` Tailwind** diabaikan browser di dalam shadow root, sehingga
  `translate-*`, `shadow-*` dan sejenisnya rusak. `element.tsx` memindahkan
  aturan-aturan itu ke `<head>` halaman sekali saja.
- **Tipe publik** (`types/index.d.ts`) ditulis tangan supaya rapi untuk
  pemakai. `types/check.ts` membuat build gagal kalau tipe itu tidak cocok lagi
  dengan kode sumbernya.
- **Komponen tool** sebaiknya menerima props untuk pemakaian di luar situs
  (lihat `ScreenRecorderProps`: `persist`, `onRecording`, `showInTitle`), lalu
  `element.tsx` menerjemahkannya menjadi atribut dan event.
- **Teks UI** dua bahasa lewat `t()` di komponen tool; atribut `lang="en"` /
  `lang="id"` memilihnya, tanpa atribut ikut bahasa browser pengunjung.
  Teks yang ditulis langsung tanpa `t()` tetap muncul dalam bahasa Indonesia,
  jadi cek tampilan `lang="en"` sebelum terbit.
- **Latar belakang**: elemen punya latar sendiri (`bg-background`), supaya
  `theme="dark"` tetap terbaca di halaman terang.

## Build dan uji

```bash
npm run build:packages            # dari root repo: type-check + build semua paket
```

Uji di halaman HTML biasa di luar situs ini, dengan CSS yang "nakal", supaya
isolasi gaya benar-benar teruji. Lihat contoh di README paket.

## Menerbitkan ke npm

Hanya pemilik akun npm yang bisa menjalankan langkah ini.

1. **Sekali saja:** buat akun di https://www.npmjs.com/signup dengan username
   **`chalidade`**. Nama paket `@chalidade/...` hanya bisa diterbitkan oleh user
   atau organisasi bernama `chalidade`. Kalau username itu sudah dipakai orang,
   ganti `name` di `package.json` paket (dan di `src/tools/registry.ts`).
2. Login di terminal: `npm login`
3. Build dan terbitkan (akun memakai 2FA lewat browser, jadi pakai `--auth-type=web`):
   ```bash
   cd packages/<paket>
   npm publish --access public --auth-type=web   # prepublishOnly menjalankan build otomatis
   ```
4. Di `src/tools/registry.ts`, ubah `package.published` menjadi `true` untuk tool
   itu. Halaman tool lalu menampilkan tab "Satu tag script" dan "npm" di bagian
   **Pasang di situsmu**. Commit dan push.
5. Cek: `https://cdn.jsdelivr.net/npm/@chalidade/<paket>@0/dist/element.js`
   (jsDelivr butuh beberapa menit setelah publish).

**Versi berikutnya:** naikkan `version` di `package.json` paket (`0.1.1` untuk
perbaikan, `0.2.0` untuk fitur baru), lalu publish lagi. Snippet memakai
`@0`, jadi pemasang otomatis mendapat versi 0.x terbaru.

## Menambah paket untuk tool lain

Generator membuat kerangka yang sama untuk semua paket (package.json,
vite/tsconfig, `element.tsx` lewat `_shared/define-element.tsx`, `element.css`
lewat `_shared/base.css`, LICENSE, THIRD-PARTY-NOTICES):

```bash
node scripts/new-package.mjs <nama> <folder-tool> <tag-elemen> <Komponen> "<deskripsi Inggris>"
node scripts/new-package.mjs uuid uuid uuid-generator Uuid "Generate UUID v4 and v7 …"
```

Lalu tulis sendiri bagian yang khas tiap tool:

1. `src/index.ts`: ekspor API tanpa UI dari file logika tool (mis.
   `src/tools/uuid/uuid.ts`). Kalau logika masih menyatu dengan komponen,
   pisahkan dulu.
2. `types/index.d.ts` (tipe publik, ditulis tangan) dan `types/check.ts`
   (memastikan tipe itu sama dengan sumbernya).
3. `README.md` dalam bahasa Inggris. Jalankan contoh kodenya terhadap
   `dist/index.js` supaya output di README benar.
4. Tambahkan field `package` di `src/tools/registry.ts`. `npm run build:packages`
   otomatis mem-build semua folder di `packages/` yang punya `package.json`.
5. Uji elemennya di halaman HTML biasa dengan CSS "nakal" dan `lang="en"`.
6. Library pihak ketiga yang ikut ter-bundle masuk ke THIRD-PARTY-NOTICES.

Elemen dengan atribut atau event tambahan (seperti `persist` dan `recording` di
screen-recorder) memakai opsi `attributes` dan `render(el)` di
`defineToolElement`.

Tool yang memakai WASM atau worker (qpdf, pdf.js, zxing, libheif, encoder
Mediabunny) tidak butuh langkah khusus: Vite lib mode memasukkan impor `?url`
sebagai data URL ke chunk yang dimuat saat dipakai, dan itu teruji jalan dari
paket (juga dari origin lain seperti CDN). Harganya ukuran: sekitar 35–50% lebih
besar daripada file terpisah, dan tiap paket membawa salinannya sendiri.
Situs pemasang dengan Content-Security-Policy ketat perlu mengizinkannya
(README paket yang bersangkutan mencantumkan kebijakan yang sudah diuji, mis.
`script-src 'self' data: 'wasm-unsafe-eval'; worker-src blob:; connect-src 'self' data:`).

Worker yang dibuat dengan `new Worker(new URL(...))` (bpm-key) harus di-inline
(`?worker&inline`, lihat `packages/bpm-key/vite.config.ts`), karena browser
menolak worker dari origin lain. Link ke situs ini yang dibangun dari
`import.meta.env.BASE_URL` perlu `define` ke `https://chalidade.github.io/tools/`
di vite.config.ts paketnya, kalau tidak link itu mengarah ke situs pemasang.

## Hal yang perlu diingat saat tool dipasang di situs orang

- **Penyimpanan** (localStorage / IndexedDB) jatuh ke origin situs pemasang.
  Tool yang menyimpan data (notes, whiteboard, tasbih, calculator, kwitansi,
  audio-recorder, screen-recorder) punya atribut `persist="false"`.
- **Keyboard**: di dalam Shadow DOM, `e.target` pada listener `window` adalah
  elemen host. Cek "sedang mengetik di input" harus memakai
  `e.composedPath()[0]`, dan shortcut sebaiknya hanya aktif saat fokus ada di
  dalam elemen.
- **Kamera / mikrofon**: lepas track saat elemen dicopot, termasuk ketika
  prompt izin masih terbuka (stream yang datang terlambat harus di-`stop()`).
